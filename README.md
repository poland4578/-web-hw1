## 어려웠던 점 3가지와 해결
1. HTML 태그의 구조와 배치
- 어려웠던 점: 영화 카드 10개를 추가하는 과정에서 <div>, <article>, <section> 등의 태그를 어디서 닫아야 하는지 헷갈렸음.
- 해결 방법: 여는 태그와 닫는 태그의 순서를 확인하고, 잘못 작성된 <div>를 수정하여 HTML 구조를 정리함.
2. CSS를 이용한 순위 변동 표시
- 어려웠던 점: 박스오피스 순위 변동을 숫자가 아닌 ▲, ▼ 등의 기호로 표시하는 과정에서 ::before 사용법을 이해하기 어려웠음.
- 해결 방법: CSS 가상 요소의 역할을 알아보고, .change.up::before와 .change.down::before를 각각 설정하여 기호와 색상을 표시함.
3. 화면 크기에 따른 반응형 레이아웃
- 어려웠던 점: 영화 카드가 한 줄에 5개씩 표시되는 등 화면 크기에 맞춰 카드의 개수를 조절하기 어려웠음.
- 해결 방법: grid-template-columns와 @media의 작동 방식을 확인하고, 화면 너비에 따라 1열·2열·4열로 변경되도록 CSS를 수정함.
